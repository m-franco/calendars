## Calendarios deportivos

Sitio para suscribirse a calendarios de torneos CONMEBOL, como Copa Libertadores y Copa Sudamericana.

Permite elegir calendarios por torneo completo, país, grupo o equipo. Una vez suscripto, los partidos quedan disponibles en el calendario del teléfono o la computadora.

### Calendarios disponibles

- Copa Libertadores
- Copa Sudamericana

### Opciones de suscripción

- Apple iCal
- Google Calendar
- Microsoft Outlook
- Outlook.com

### Sitio

https://m-franco.github.io/calendars/

- Google Calendar
